# 实验模型与教学边界

这些模型用于建立可操作、可解释的直觉。模拟周期、容量和时延不是现实硬件或网络的测量值。模型状态转移可以独立测试，页面只负责呈现状态与发送 Action。

| 模型              | 实现的机制                                                                                 | 明确的边界                                                                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Binary            | 8 位表示、逐位逻辑、加法低位与 Carry、NOT、左移                                            | 仅无符号；不是补码或有符号溢出实验。当前工厂仅支持 width = 8。                                                                             |
| CPU               | MOV / ADD / STORE / LOAD / HALT；IR、PC、寄存器、ALU、数据内存；四个执行阶段               | 自定义教学指令集、16 位寄存器、按指令索引的 PC；无流水线、乱序、真实周期建模。                                                             |
| Pipeline          | 单发射五级流水线、RAW 检测、IF / ID 保持与气泡、EX / MEM 转发、load-use 停顿、顺序执行对照 | 16 位寄存器、分离的指令 / 数据内存、固定单周期访存；STORE 在 EX 取源值、MEM 写入。无分支、结构冒险、Cache Miss、乱序或异常。               |
| Branch Prediction | 静态 N、1 位历史、2 位饱和计数器、预测 / 揭晓分步、相同分支序列对照                        | 同一条件分支，最多 64 次；不模拟目标地址、BTB、全局历史或真实指令冲刷。固定误判罚时只用于估计额外周期。                                    |
| Cache             | 16 B 行，L1 4 行 / L2 8 行，直接映射，包含式 L2 驱逐与 L1 失效                             | 只读，无预取、写回、关联度或多核一致性。1 / 8 / 80 模拟周期按串行路径累加。当前仅支持 lineSize = 16。                                      |
| Process / Thread  | 单核轮转、时间片、阻塞与条件等待、唤醒、PC / 栈帧保存、同进程共享计数                      | Blocked / Waiting 是教学分类，栈简化为一个局部计数器。每一步计数增量是原子的；没有竞态、多核或完整内核上下文。                             |
| Virtual Memory    | VPN / Offset / PFN，8 页、4 帧、256 B 页，2 项 LRU TLB，缺页重试与 FIFO 置换               | 单进程、只读、单级页表。合法页可能不驻留；不模拟非法映射、权限、脏页、真实存储延迟。                                                       |
| TCP Handshake     | 两端状态、独立 ISN、Seq / Ack、丢包、手动重传、重复 SYN、错误 ACK                          | 只演示常规主动 / 被动打开；不模拟窗口、超时算法、SYN cookies、同时打开。错误 ACK 的 RST 响应可见，但 Client 对 RST 的验序 / 复位分支省略。 |
| TCP Close         | 两个 FIN、对应 ACK、半关闭数据、LAST_ACK、重传 FIN、TIME_WAIT                              | 拆成典型四段；现实 ACK / FIN 可以合并。本模型在最后 ACK 送达后才允许推进教学计时，真实两端计时器独立。                                     |
| DNS               | 解析器逐级迭代、根 / TLD 转介、权威 A / NXDOMAIN、60 s 正缓存、30 s 负缓存                 | 隔离 .test 域与 RFC 文档 IP。仅缓存最终记录，省略 NS / glue 缓存、CNAME、DNSSEC 与传输协议。                                               |
| HTTP              | URL、DNS、TCP、抽象 TLS 1.3、HTTP/1.1、服务端响应、同源连接复用、分层故障                  | 所有数据均为本地模拟，不执行网络请求；无 HTTP/2 / HTTP/3、代理、TLS 恢复和子资源。DNS 缓存不计 TTL，TTL 见 DNS 课。                        |
| B+Tree            | 4 阶唯一键树、上下级分裂、兄弟借位、合并、根增减、叶子链表和范围扫描                       | 每键抽象代表一条记录；节点容量按键数，界面最多 64 条。不等同于完整 InnoDB：无磁盘持久化、并发或事务。                                      |

## 第二阶段新增模型

第二阶段还加入以下模型，它们与第一阶段共享 Session / Workbench，不共享可变算法状态：

| 模型                  | 实现的机制                                                                   | 明确的边界                                                                                                           |
| --------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| CPU Scheduling        | FCFS / SJF / SRTF / RR、到达事件、抢占、等待 / 响应 / 周转、相同输入对照     | 单核、已知 CPU burst、整数时间；无 IO、优先级、多核或切换耗时。RR 边界先加入新到达任务，再重新排队耗尽时间片的任务。 |
| Page Replacement      | FIFO / LRU / Clock / OPT、引用位、替换轨迹与 Belady 异常                     | 1–5 帧、最多 40 次合法只读页访问；无脏页、磁盘计时、TLB。OPT 预知未来，只作离线下界。                                |
| TCP Reliability       | 固定段字节序号、累计 ACK、乱序缓冲、应用读取、RTO 重传、重复段去重、窗口更新 | 已建立的单向连接，每段 100 B、4–12 段；不模拟拥塞、SACK、回绕、恶意 ACK、真实定时器或零窗口探测。                    |
| TCP Congestion        | Reno 每 ACK 增长、FlightSize 阈值、三次重复 ACK、快速恢复与 RTO              | 初始 cwnd=1 MSS 是教学选择；每段一个新 ACK，单次丢包；省略延迟 ACK、SACK、多重丢包、CUBIC / BBR、RTO 估计。          |
| Arrays / Lists        | 数组后缀搬移、单链表 head / next 增删、按索引定位、同位置插入对照            | UI 最多 12 项；成本分别统计元素读写或节点访问 / 链接写入，省略分配、释放、扩容与真实缓存耗时。                       |
| Stack / Queue / Deque | LIFO / FIFO、双端操作、固定容量环形槽位、满空拒绝与复用                      | 2–8 个槽位，以 size 区分满空；无自动扩容、阻塞、并发同步或无锁内存序。                                               |
| Hash Table            | 非负取模、线性探测、墓碑、同键更新、手动重新散列                             | 容量 7 可扩至 13；整数键值；不实现自动增长 / 缩容、链地址法或并发。                                                  |
| Binary Search         | lower_bound、半开区间、重复键最左位置、插入点与比较数                        | 要求 1–24 个已排序整数，不自动排序；只测数组上的比较过程。                                                           |
| Sorting               | 相邻交换插入排序、选择排序、稳定归并、原始编号、比较 / 写入计数              | 最多 16 项；写入包括归并缓冲与写回，无原地合并、移动优化插入排序、并行或真实性能计时。                               |
| BST / Min Heap        | BST 唯一键增删查、后继替换；完全二叉堆上浮 / 下沉 / 读根                     | UI 最多 15 项；BST 无平衡，堆允许重复值；树形视图不意味着 BST 总有对数高度。                                         |
| Graph                 | 可编辑方向与权重、BFS / DFS / Dijkstra、前驱、路径代价、不可达与同图比较     | 固定 A–F，最多 20 条唯一边，非负权 0–20，无自环；边列表扫描邻居，候选集直接排序，不声称采用高性能堆实现。            |
| Greedy / DP           | 无限硬币最少枚数、局部最大选择、逐金额 DP、不可达与方案回溯                  | 1–6 种正面额、目标 1–40；无有限库存或全部方案枚举，DP 复杂度依赖金额数值。                                           |

## Level 0–4 补齐模型

| 模型              | 实现的机制                                                                        | 明确的边界                                                                                          |
| ----------------- | --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Modeling          | 专用解释器、ACC / PC、输入输出、条件跳转、状态预测与 HALT                         | 1–16 条指令；每次运行最多 200 步，预算暂停不算停机；不执行任意脚本。                                |
| Signed Number     | 4 / 8 位补码、逐位加减、最高位进位与 Overflow 的独立判断                          | 无乘除与饱和算术；减法 Carry 表示无无符号借位，语言层溢出规则另行定义。                             |
| Floating Point    | 精确有理数直接舍入为 IEEE binary32、最近偶数舍入、正规 / 次正规、特殊值与精确误差 | 最多 24 位十进制数字、指数 −60..60；只转换和加法，不实现完整异常标志或其他舍入模式。                |
| Encoding          | UTF-8 编码与严格解码、Unicode 标量值、UTF-16 单元、非法序列与往返                 | 文字最多 32 个 UTF-16 单元；无规范化、字素簇、字体塑形或流式缓存；BOM 保留为 U+FEFF。               |
| Boolean Logic     | 安全表达式解析、逐门求值、八行真值表、等价判断与具体反例                          | 仅 A / B / C、0 / 1、NOT / AND / XOR / OR，最多 120 字符、64 节点；无电压、延迟或时序逻辑。         |
| Interrupt / DMA   | 设备 FIFO、PIO、DMA 设置与传输、中断入口 / 返回、相同工作量对照                   | 一个逻辑时隙最多一字节；PIO 读写合并，后台仅用寄存器，不模拟总线竞争、IOMMU 或缓存一致性。          |
| File System       | 目录到 inode、硬链接、独立 open 偏移、unlink 后引用保留、块分配与回收             | 单目录 / 单进程，12 个 4 字节块、8 个 inode / FD；整文件替换是教学原子操作，非完整 POSIX 写入语义。 |
| Page Cache / mmap | 惰性驻留、文件缓存命中、共享修改、私有 COW、LRU 脏页写回、撤销映射与重启          | 四文件页、两进程；私有页独立占内存且不回收；未模拟文件元数据、设备缓存和完整持久化屏障。            |
| IO Multiplexing   | FD 接收字节、阻塞等待 / EAGAIN、select / poll / epoll LT / ET、到达通知合并和排空 | 固定三个 FD、每缓冲 16 字节，零超时检查；扫描计数是概念示意；无关闭、写就绪或并发竞争。             |
| Network Layers    | IPv4 子网与下一跳、链路 ARP、逐跳 MAC、TTL、UDP / TCP Socket 分用和错误定位       | 两个文档网段、一个路由器，无 NAT / 分片 / 校验和；TCP 预先建立；无真实网络请求。                    |
| TLS               | 小群 DH 模幂、证书信任 / 名称 / 时间条件、握手绑定、Finished 失败阻断与字节还原   | p=23 与 XOR 只是玩具算术；签名 / Finished 是抽象验证，不实现真实 X.509、HKDF、AEAD 或完整 TLS。     |

## 数据库原理模型

| 模型              | 实现的机制                                                                           | 明确的边界                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| Database Pages    | 固定记录与页容量、主键约束、页缓存命中、pin 引用、脏页写回与 LRU                     | 六个 64 B 页，每页三条记录；Buffer Pool 1–3 帧；无事务与日志，按主键定位使用元数据。              |
| WAL / Redo / Undo | before / after、pageLSN、持久日志前缀、先日志后页、steal / no-force、崩溃重做与撤销  | 单线程、事务不交错、整页写入；恢复整体完成，无 ARIES / CLR / 检查点或恢复期间崩溃。               |
| Transactions      | 私有写集、同序号多行提交、回滚、RU / RC / RR、点读取两阶段锁、当前读、等待与死锁检测 | 两行、两会话；RR 当前更新按 InnoDB 风格，不代表所有数据库；无插入 / 范围锁、版本清理或持久日志。  |
| Query Optimizer   | 真实 B+Tree 复合键、叶项 RID、堆表取记录、独立扫描与索引路径、过时统计和 ANALYZE     | 24 行、8 个数据页，索引内部节点已缓存，叶页 / 数据页冷启动；固定教学成本，无连接或真实 SQL 解析。 |

## MySQL 模型

| 模型            | 实现的机制                                                                        | 明确的边界                                                                                                    |
| --------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| InnoDB Indexes  | 两棵真实 B+Tree、二级主键回表、字段覆盖与同步增删                                 | 4 阶、最多 12 行、逻辑访问；不模拟现实 MVCC 可见性导致的额外聚簇访问。                                        |
| InnoDB Commit   | 持久 PREPARE / 完整 Binlog XID 决定、崩溃恢复与一次性复制应用                     | 单行串行、保留日志、保守持久顺序；无 XA / 组提交 / 弱刷盘配置或恢复中再次崩溃。                               |
| Read View       | creator / ID 边界 / 活跃集合、真实 Undo 链、RC / RR、回滚与快照保护的清理         | 三会话单行，所有 BEGIN 分配教学 ID；Purge 按本行保留前缀，不模拟全局回滚段。                                  |
| InnoDB Locks    | 唯一等值与下界范围的记录 / 间隙 / Next-Key、等待与重试、RR / RC 对照              | 保守扫描区间；实际足迹与版本计划有关；无外键、重复检查例外、共享锁或 Insert Intention。                       |
| MySQL Execution | 三种独立 Join、实际 GROUP BY / ORDER BY / LIMIT、显式排序段与归并、估计与实际成本 | 固定模板、唯一客户键、无 NULL / 外连接，索引为抽象 Map；Filesort 溢出模拟不写真实文件，城市按字符值打破并列。 |

## Java 核心模型

| 模型                     | 实现的机制                                                                                    | 明确的边界                                                                              |
| ------------------------ | --------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Java Objects             | 对象身份、引用别名、共享字段、参数复制、局部重绑与栈可达性                                    | 单线程 Box、无字段引用图与 GC；编号不是物理地址，无真实字节码与标量替换。               |
| ClassLoader / Reflection | 父委派与独立类型、延迟初始化、固定方法检查与执行、finally / 包装异常 / cause                  | 两加载器一类，无 .class 解析、模块权限、链接约束或 suppressed 异常。                    |
| Java Collections         | ArrayList 增长 / 搬移、String.hashCode、链式 HashMap 扩容、Set 去重、泛型污染和迭代器结构计数 | 最多 16 项，无 null / 树桶 / 并发；raw 污染仅 List / Map，HashMap 顺序不承诺稳定。      |

| Java IO APIs             | 字节 / UTF-16 单元读取、EOF、close、ByteBuffer position / limit、flip / get / compact         | 内存文件，Reader 预先解码为等价单元序列；无真实 Java IO、解码预读成本与可选择网络通道。 |

## Java 并发模型

| 模型               | 实现的机制                                                         | 明确的边界                                                                                         |
| ------------------ | ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| Thread / Atomic    | 交错读写、CAS 失败重试、ABA 版本、join 与协作中断                  | 两线程各一次自增；带版本逻辑值并非 AtomicStampedReference 的引用身份；不模拟弱 CAS 或 stamp 回绕。 |
| Monitor / AQS      | 重入持有、同步与条件集合、通知后重获取、while 谓词检查             | synchronized 不基于 AQS；单锁单条件；无底层 park、超时、中断或 tryLock 公平例外。                  |
| Latch / Semaphore  | 完成前发布、一次门闩、许可获取与归还、超额 release                 | 三任务；资源包装器约束不是 Semaphore 的所有权规则；新建实例不等于 reset API。                      |
| ThreadPoolExecutor | core → offer → max → rejection，CallerRuns，shutdown / shutdownNow | 确定服务时隙；无 CPU 竞争、keepAlive、运行异常或动态调整；外部 caller 工作独立于 pool 终止。       |
| ConcurrentHashMap  | get + put 反例、桶级 compute、逐桶扩容与转发读写                   | 链式教学桶；无空桶 CAS、树桶、size 或协作迁移；保留旧表供观察。                                    |
| ForkJoin / Future  | 真实分治求和、双端队列窃取、依赖回调、异常恢复和取消               | 两 worker 显式执行器，无线程补偿；非 Async 演示完成线程路径；取消 future 不保证中断底层工作。      |

## Spring 模型

| 模型              | 实现的机制                                                                                 | 明确的边界                                                                                                   |

## 为什么选择这些边界

一个好的实验应让用户建立一个可以解释现象的模型，而不是同时暴露所有实现细节。课程说明哪些结论可以迁移，哪些只属于本模型；新增机制前先给出一个新的、可检验的问题。

特别注意：

- Server 收到 SYN 已经表明这个 SYN 能到达。最后 ACK 确认 Server 的初始序号及前一步消息的接收，不能仅用“证明双向通信”取代具体状态解释。
- SYN / FIN 各消耗一个序列号，纯 ACK 不消耗。所有握手序列号按模 2³² 回绕。
- TLB Miss 不一定缺页；缓存映射失效不等于对应页面不在 RAM。
- HTTP 500 是收到的应用层响应，不能解释成 TCP 建连失败。
- B+Tree 内部的导航键不是额外记录；删除和借位后必须更新分隔键与叶子链表。
- Cache 对照组从冷缓存开始，包含相同地址集合、相同访问次数，使用固定种子的排列。顺序差异不会被偷偷换成数据集差异。
- 浮点先将十进制字符串解析为精确有理数，直接舍入到 binary32；不让 JavaScript binary64 的双重舍入改变边界结果。
- inode 的硬链接数与打开引用分别检查；文件缓存淘汰会撤销相应映射，脏数据先写回，私有 COW 页不混入文件持久化。
- epoll ET 不保证为未读完的字节再次通知，但新到达可以产生通知；EAGAIN 不等于 EOF。
- TLS 的共享值一致不是身份证明；证书、握手绑定或 Finished 失败时都不能产生应用交付。
- 数据库 pin 保护缓冲帧，事务锁协调读写，dirty 决定写回需要，三者不能混为一谈；持久 UPDATE 也不能代替持久 COMMIT。
- 查询路径比较固定索引插入顺序与输入表，只改变指定变量。索引通过独立 RID 元数据关联数据页，不把未覆盖字段当成叶节点已有数据。
- volatile 不使自增原子化；Condition 通知不转交锁所有权；Semaphore 的超额 release 不受初始许可数自动限制。
- flush 把字节交给下一层，不自动保证断电持久性；Selector 就绪不表示完整消息已经到达；@Valid 本身不拒绝 null。
- Kafka 事务不包含外部数据库效果；RabbitMQ publisher confirm、mandatory return 与 consumer ack 是不同边界。
- Raft 已提交前缀不能被修复过程覆盖；Fencing 只拒绝比资源已见版本更旧的 token；2PC 参与者不能在 prepared 后仅凭超时猜测全局决定。
- Outbox 与 Inbox 支持可恢复重试，仍允许短暂缓存滞后与重复传输；relay 租约不能消除发布与标记之间的故障间隙。
- 容量比较保持输入、业务结果和接纳量一致；有限负载的 Little 定律核对使用完整排空区间。IO 等待不计入 JVM CPU 样本，十二请求的错误预算比例不能当作生产告警统计。

## 验证策略

- 单元测试覆盖边界状态、失效和恢复路径，以及独立 Session 的隔离与重置。
- 流水线验证相同程序在三种执行方式下结果一致、写回边界、最近写入的转发优先级及 load-use 的单周期气泡；分支预测验证先预测后训练、计数器饱和、错误输入恢复，以及 2 位不总优于 1 位的序列。
- B+Tree 使用六组固定种子的 64 键插入 / 删除序列，每次操作后检查容量、排序、分隔键、统一叶子深度、记录集合与链表完整性。
- 调度验证到达 / RR 边界、抢占、工作量守恒与指标；页面置换验证 FIFO 异常、LRU 容量单调性、Clock 引用位和 OPT 下界。
- TCP 传输验证 ACK 丢失与数据缺口、窗口关闭、重传去重；Reno 验证只由新 ACK 增长、按实际在途量减半与不同恢复路径。
- 数组、链表、环形队列与哈希表对照独立数组 / Map；BST 逐节点检查后代边界，堆对照最小值序列。
- 排序检查完整记录集合、重复键稳定性与操作计数；二分逐步检查不变量；Dijkstra 对照 Floyd–Warshall，找零 DP 对照广度优先枚举的最短解。
- 补码对全部 4 位操作数组合验证结果、进位与溢出；浮点覆盖中点、次正规边界、溢出及十进制双重舍入反例；UTF-8 对照 TextEncoder 并拒绝非法序列。
- 设备 IO 检查数据与 CPU 时间守恒；文件系统检查引用和块唯一性；Page Cache 检查缺页与磁盘读取分离、脏页回收和 COW 隔离；ET 验证新到达与部分读取通知。
- 网络检验下一跳 ARP、逐跳头部、TTL 与端口失败；TLS 以独立 BigInt 模幂验证共享值，检查三类证书失败及两类握手改动。
- 数据库检查页容量、主键、pin 引用和脏页回收；WAL 遍历提交阶段与刷盘组合，验证恢复后的余额、未提交撤销和重复恢复；事务验证快照时点、当前更新、语句重试、原子回滚与真实等待环。
- 查询路径与独立过滤结果对照，跨物理布局、类别和 IO 成本检查记录集合；过时统计与更新统计分别决定可解释的实际计划。
- MySQL 遍历内部提交崩溃时点、检查两个索引一致性、Read View 边界和版本链；锁区间区分记录与插入，三种 Join 对照独立关系结果并跨容量检查排序。
- Java 核心验证引用别名与返回边界、加载器身份、反射 cause；集合跨容量对照 Map，UTF-16 hash 对照独立 BigInt；发布检查传递可见性，IO 跨字节 / 代理对边界对照标准编码。
- JVM 验证错误字节码、初始化失败与内存容量；GC 对随机环图核对独立可达性、单代边界、晋升原子性和引用完整性；搬迁保持身份和值，JIT 对相同输入核对结果、分配和守卫失效。
- 并发验证丢失更新与 CAS 重试、ABA、join / interrupt、条件重获取与谓词重检、许可复用与超额 release、线程池接纳 / 关闭、桶迁移与 ForkJoin 真实求和和取消边界。
- IO / NIO 对照原始 UTF-8 字节，检查缓冲调用数、force 恢复、selected keys、半包 / 部分写、EOF、卸载顺序、引用生命周期与背压。
- Spring 验证候选歧义、循环依赖、作用域和销毁；转账对照提交余额、异常回滚与传播，拒绝不能进入的调用；MVC 检查路由、绑定、异常、协商与转义。
- Boot 验证配置优先级、条件退让与重启边界，区分类型绑定、约束、嵌套 null、readiness / liveness、暴露和授权。
- Redis 随机更新后检查每层跳表链与成员集合；核对类型错误、整数溢出、TTL / 淘汰、持久前缀与重写崩溃，使用独立 CRC16 向量检查槽规则与迁移。
- 消息验证 offset 提交时点、消费组世代、重复与丢失、Kafka 事务范围、RabbitMQ 路由通配符、确认边界、重投与 inbox。
- 分布式验证仲裁拒绝与修复、Raft 竞争选举 / 延迟消息 / 日志新旧 / 前缀修复、租约与旧 token、2PC 持久决定、Saga 幂等补偿、发现快照、预算与半开探测。
- 后端容量逐时隙核对 CPU、连接、worker 和堆约束，用在途数量积分独立核对总响应时间；缓存 / outbox 验证崩溃接管、乱序和去重；诊断验证证据来自真实工作量，单变量调整保持结果并减少尾延迟或 GC。
- Playwright 在桌面与手机视口实际操作 81 个实验，并验证挑战、进度持久化、无效输入、模式切换、导航与 Tutor 对话框。
- Axe 自动检查全部课程和路线页的 WCAG A / AA 规则；自动扫描不能替代完整的人工无障碍评估。
- 每次 main push 都先测试与构建，成功后才发布 Pages。
