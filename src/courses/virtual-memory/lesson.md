## Problem · 地址需要稳定，物理位置却会改变

多个进程可能都使用地址 0x012C，但它们不应该因此共享数据。物理内存有限，也未必有一整块连续空间容纳程序。

## Why · 加一层映射，解耦两个视图

程序看到虚拟地址；硬件结合当前进程的页表找到物理地址。不同页表可以把同一个虚拟地址指向不同物理帧。这个实验固定观察**一个进程**的页表，隔离边界可以回看进程与线程课程。

虚拟空间按固定大小切成**页（Page）**，物理内存按同样大小切成**页帧（Frame）**。页表记录“虚拟页放在哪个物理帧”。程序中相邻的虚拟页可以位于不相邻的物理帧，程序仍使用原来的虚拟地址。

映射也让操作系统可以暂时不把全部页面放进物理内存。访问时再准备页面，就需要一条能暂停访问、处理缺页、重试访问的路径。虚拟地址空间大，不代表物理内存或磁盘容量真的无限。

## Mechanism · 页号变化，偏移不变

本模型每页 256 B：VPN = 虚拟地址 ÷ 256 取整，Offset = 虚拟地址 % 256。页表给出 PFN 后，物理地址 = PFN × 256 + Offset。

TLB 首先缓存转换结果。TLB Miss 时继续查页表，只有 Present = 0 才在本模型中触发缺页。操作系统分配帧、载入数据、更新映射，之后重试原访问。

### 手算一次地址转换

虚拟地址 `0x012C` 是十进制 300：

```text
300 = 1 × 256 + 44
VPN = 1，Offset = 44
页表：VPN 1 → PFN 0
物理地址 = 0 × 256 + 44 = 44 = 0x002C
```

VPN 是虚拟页号，PFN 是物理帧号，Offset 是页内偏移。转换改变页面的位置，但同一页面内部第 44 个字节仍是第 44 个字节，所以偏移保持不变。本例每页 256 B，低 8 位正好表示偏移。

页表并不保证 VPN 与 PFN 相同。默认 VPN 0、1、3 分别映射到 PFN 2、0、1，VPN 2 尚未驻留；不能把虚拟页号直接拿来当物理帧号。

### 三条访问路径

| 观察结果                   | 缺少什么     | 后续工作                 |
| -------------------------- | ------------ | ------------------------ |
| TLB Hit                    | 无需再找转换 | 直接组合物理地址         |
| TLB Miss，页表 Present = 1 | 快速转换缓存 | 查页表并回填 TLB         |
| TLB Miss，页表 Present = 0 | 驻留的页面   | 处理缺页，更新映射并重试 |

TLB 缓存的是**地址转换**，CPU Cache 缓存的是**内存数据**。清空 TLB 不会把物理页删除，也不等于清空 CPU Cache。这是不同对象的两种缓存。

物理帧用满时，本课按 FIFO 选择最早载入的虚拟页，清除旧页的驻留映射，再把该帧交给新页。旧 TLB 项如果还在，也必须失效；否则旧地址会错误地指向新页面。

## Experiment · 分清两种“找不到”

1. 重置，输入 0x012C，点击“访问地址 · 查询 TLB”。首次出现 TLB Miss，物理地址还没有得出。点击“查询页表”，确认 VPN = 1、Offset = 44、PFN = 0，最终物理地址为 0x002C，缺页次数仍为 0。
2. 再点“访问地址 · 查询 TLB”，这次直接命中，TLB Hits 增加，页表查询次数不增加。将地址改为 0x012D 再访问，同一页的映射仍可复用，物理地址应为 0x002D。
3. 输入 0x022A，依次查询 TLB、页表。VPN = 2 尚未驻留，出现一次 Page Fault。点击“处理缺页并重试”，空闲 PFN 3 被分配，物理地址为 `3 × 256 + 42 = 810`，即 0x032A。观察命中和完成缺页处理后，实验目标达成。
4. 点击“清空 TLB”，重新访问 0x022A 并查询页表。页仍驻留，所以只增加页表查询，不增加缺页次数。
5. 选做：在上述步骤后访问 0x0400，查页表并处理缺页。四个帧已经占满，FIFO 换出最早载入的 VPN 1，让 VPN 4 使用 PFN 0。之后再访问 0x012C，说明为什么这次可能需要重新载入页面。

每次访问前预测属于表中的哪条路径，再记录 **VPN、Offset、PFN、物理地址、TLB Hits、Page Faults**。正在查表或处理缺页时，地址输入会锁定，先完成这次访问再切换地址。

## Conclusion · 缓存缺失不等于数据缺失

本实验有 8 个虚拟页、4 个物理帧和 2 项 LRU TLB，省略多级页表、权限检查、脏页和真实磁盘延迟。页面置换采用 FIFO 教学策略，不能据此推断真实操作系统的全部行为。

自检：访问合法地址却缺页，是程序写错了吗？本课中只是页面尚未驻留，处理后原访问可以继续。真实系统还存在按需分配、写时复制、权限故障等情况，缺页异常也不一定需要磁盘 IO；本课只展示其中的载入路径。
