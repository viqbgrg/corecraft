## Problem · 从一次熟悉的计算开始

你在计算器里输入 3，再加上 2，就会看到 5。结果很容易算出来，但计算机是怎样把输入变成结果的？

这一课只需要会做简单的加法。我们用一台小机器，把“读入数字、按规则处理、显示结果”拆开来看。先建立对整个过程的认识，遇到的新词都会用这个例子解释。

## Why · 先认识计算机做的几件事

计算机是一种能按照程序处理信息的机器。我们先从它做的事情来认识它：

| 事情                     | 在这个例子里是什么           |
| ------------------------ | ---------------------------- |
| 输入：接收信息           | 交给小机器一个数字 3         |
| 处理：按规则做事         | 给这个数字加上 2             |
| 暂存：记下还会用到的信息 | 先记住读入的 3，算完后记住 5 |
| 输出：把结果交出来       | 显示计算得到的 5             |

这里的“记住”是计算过程中的临时记录。它让下一步能接着使用前一步的结果，和把文件长期保存下来是不同的问题。

计算机处理的也不只有数字。输入一段文字、调整一张照片，都涉及接收信息、处理信息和给出结果。本课先用数字，是因为每一步的变化都容易检查。

## Mechanism · 看清过程，再给概念起名字

实验默认输入 3，处理规则是“加 2”。每次点击“执行下一步”，只做下面的一件事：

| 步骤    | 小机器做什么       | 当前记住的数 | 输出     |
| ------- | ------------------ | ------------ | -------- |
| 开始前  | 等待操作           | 还没读取     | 还没显示 |
| 第 1 步 | 读入输入的数字     | 3            | 还没显示 |
| 第 2 步 | 把记住的数加上 2   | 5            | 还没显示 |
| 第 3 步 | 把记住的数显示出来 | 5            | 5        |

注意第 2 步：结果已经算出来了，但还没有显示。**算出结果和输出结果是两件事。** 实验把它们分开，帮助我们看到平时藏在屏幕后面的过程。

现在再认识几个词：

- **数据**是被处理的信息。在这里，输入的 3、中间得到的 5、输出的 5 都是数据。
- **状态**描述“现在是什么情况”。例如，当前记住的是 3 还是 5，做到哪一步，结果是否已经显示。这些信息决定接下来会发生什么。
- **指令**可以先理解为一个明确的操作，例如“加上 2”；**程序**把操作组织成步骤，例如“读入 → 加 2 → 显示”。这里用中文帮助理解，真实计算机怎样表示和执行这些操作，会在后续课程展开。

这台小机器就是一个**模型**：它保留了我们当前想研究的输入、规则、中间过程和输出。建立这样一个简化的解释，叫做**抽象与建模**。有用的模型应该能帮我们预测：换一个输入，接下来会怎样？

## Experiment · 一次只改变一件事

先做完一个最小实验：

1. 保持输入为 3，处理规则为“加一个数”，“加多少”为 2。点击一次“执行下一步”，确认当前记住的是 3。
2. 下一步要加 2。先在“预测下一步记住的数”中填入你的猜想，再点“验证预测并执行下一步”。对照规则和观察记录，看看为什么得到这个数。
3. 再点一次“执行下一步”，让结果显示出来。比较输入、当前记住的数、输出三个区域，说明它们各自的作用。

然后做两个小变化。修改输入或规则会让实验从头开始：

4. **只改数据**：把输入从 3 改成 4，保持“加 2”。先猜输出，再逐步验证。你没有改处理规则，同样的步骤也能处理新的输入。
5. **只改规则**：保持输入为 4，把“加多少”从 2 改成 4。再次预测并观察。输入相同，规则不同，结果也可能不同。

猜错时，先看这一轮的输入和规则，再检查具体哪一步与想象不同。这就是“先预测 → 做实验 → 对照观察 → 修改解释”的学习方法。

### 选做：两条规则的顺序会影响结果吗？

熟悉一条规则后，可以把输入设为 3，“加多少”设为 2，分别选择“先加，再乘以 2”和“先乘以 2，再加”。前者依次记住 3、5、10；后者依次记住 3、6、8。

两次用到了相同的加法和乘法，顺序不同，结果就不同。程序既要说明做什么，也要组织先后次序。这部分可以稍后再试，不影响完成本课的基础实验和挑战。

## Conclusion · 先有整体认识，再逐步打开细节

学完这一课，试着用自己的话讲清楚：小机器拿到了什么数据，遵循什么步骤，中间记住了什么，最后输出了什么。能解释这四件事，就已经建立了第一个理解计算机的模型。

这个模型只处理 0–20 的整数输入，加数为 0–10，支持加法、乘以 2 及这两条规则的顺序组合。它帮助我们研究按步骤处理数据的过程；它还不能解释文字怎样存储、硬件怎样运算，也不代表计算机只能做这些事情。一次预测正确，是对解释的支持；换输入继续验证，才能知道这个解释是否仍然适用。

接下来先学习**二进制与数据表示**，理解计算机怎样表示数字和文字；之后再进入 **CPU 如何执行指令**，认识负责执行的部件，以及它们怎样保存和处理数据。每一步都在前面的认识上增加一些细节。
